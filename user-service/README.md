# User Service

User Service is responsible for managing users
of the Movie Ticket Booking System.

## Technologies

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Swagger/OpenAPI

## Port

8081

## Database

user_db

## API Endpoints

POST /api/users
GET /api/users
GET /api/users/{id}
PUT /api/users/{id}
DELETE /api/users/{id}

## Run

Run UserServiceApplication.java.

Swagger:

http://localhost:8081/swagger-ui.html
