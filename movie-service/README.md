# Movie Service

Movie Service manages movie information such
as title, genre, language, duration and ratings.

## Technologies

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Swagger

## Port

8082

## Database

movie_db

## Endpoints

POST /api/movies
GET /api/movies
GET /api/movies/{id}
PUT /api/movies/{id}
DELETE /api/movies/{id}
GET /api/movies/genre/{genre}
GET /api/movies/language/{language}

## Swagger

http://localhost:8082/swagger-ui.html
